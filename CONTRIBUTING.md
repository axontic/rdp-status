# Contributing to RDP Status Dashboard

Thank you for your interest in contributing to this project!

## How to Contribute

### Reporting Issues

- Check if the issue already exists
- Provide clear reproduction steps
- Include your environment details (OS, Node.js version, browser)

### Pull Requests

1. Fork the repository
2. Create a feature branch (`git checkout -b feature/my-feature`)
3. Make your changes
4. Test locally with `docker-compose up`
5. Commit with clear messages
6. Push to your fork
7. Open a Pull Request

### Code Style

- Use consistent indentation (2 spaces for JS, 4 spaces for PowerShell)
- Add comments for complex logic
- Keep functions focused and small

### Testing

Before submitting:

- Ensure `npm install` completes without errors
- Test the dashboard loads correctly
- If modifying the PowerShell client, test on a Windows machine

## Questions?

Open an issue for discussion.
